# Paint Studio FX

Aplicación de dibujo desarrollada en **JavaFX** utilizando:

- MVC (Modelo Vista Controlador)
- FXML
- CSS moderno
- Manejo de eventos
- Canvas de dibujo


# Características

 Lienzo/Canvas para dibujar  
 Herramienta lápiz  
 Herramienta borrador  
 Dibujar rectángulos  
 Dibujar círculos  
 Dibujar líneas  
 Selector de color  
 Selector de grosor  
 Guardar dibujo como PNG/JPG  
 Interfaz moderna con CSS  
 Arquitectura MVC  


Paint Studio FX es una aplicación de dibujo desarrollada en JavaFX siguiendo la arquitectura MVC . Permite al usuario crear dibujos sobre un lienzo utilizando diferentes herramientas como lápiz, borrador, rectángulos, círculos y líneas. Además, incorpora un selector de color, control de grosor del trazo y la posibilidad de guardar las creaciones en formato PNG o JPG. La interfaz ha sido diseñada con FXML y CSS, proporcionando una experiencia visual moderna e intuitiva, mientras que los eventos de JavaFX gestionan la interacción del usuario con las distintas herramientas de dibujo.
